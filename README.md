# PlacementAI — Chances Challenge

A responsive frontend prototype for a B.Tech CSE/AIML placement prediction platform.

## Included working modules
- Dashboard
- Student Profile with save action
- AI-style placement prediction
- What-if simulator
- Chances Challenge
- Skill Analyzer
- Company Matcher
- Resume Analyzer (client-side demo analysis)
- Mock Interview evaluator
- Personalized roadmap
- Leaderboard
- Admin analytics
- Dark mode
- CSV export
- Responsive mobile navigation

## Run
Open `index.html` in a modern browser.

## Important
The prediction logic in this prototype is a transparent demo heuristic. For a final college project, replace it with a trained ML model/API using a real dataset and report model metrics (accuracy, precision, recall, F1, confusion matrix). Do not present the probability as a guaranteed placement result.
